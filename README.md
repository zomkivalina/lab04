## Завдання варіанту
Для вкладених `list`/`tuple` чисел рекурсивно обчислити суму та кількість
елементів; додатково — максимальну глибину вкладеності та ітеративну версію з
власним стеком.

- **База рекурсії:** число → `(число, 1, 0)`; порожній контейнер → `(0, 0, 1)`.
- **Крок рекурсії:** для контейнера обчислити результат кожного елемента й
  об'єднати: суми та кількості складаються, глибина = 1 + max глибин дітей.

## Що реалізовано
**`nested.py` (варіант 6):**
- `nested_sum`, `nested_count`, `max_depth`, `nested_stats` (усе за один прохід),
  рекурсивний генератор `flatten`;
- `nested_stats_cached` з `@lru_cache` — однакові незмінні піддерева рахуються
  один раз (`freeze` перетворює list → tuple, бо кеш потребує хешованих аргументів);
- `nested_stats_iter` — без рекурсії, на власному стеку пар (елемент, глибина);
- `trampoline` + `nested_sum_trampoline` — моделювання TCO;
- перевірка типів: рядки, `None`, `bool`, словники → `TypeError`.

**`algorithms.py` (обов'язкова база):** 3-шляховий `quicksort` з випадковим pivot,
гібрид із сортуванням вставками, рекурсивні pre/in/postorder-генератори, ітеративні
BFS/DFS, висота дерева, `fib` з `lru_cache`, `fib_naive`, `fib_iter`.

## Ліміт рекурсії і TCO
CPython обмежує глибину стеку викликів: `sys.getrecursionlimit()` = 1000 за
замовчуванням, при перевищенні — `RecursionError`. Оптимізації хвостових викликів
(TCO) немає свідомо: інтерпретатор зберігає кожен кадр, щоб traceback показував
повну історію викликів. Тому навіть «хвостова» рекурсія росте в стеку.

На практиці `nested_sum` витримує лише ~490 рівнів вкладеності: кожен рівень
займає два кадри (сама функція + генераторний вираз у `sum`). Структура глибиною
600 або 10 000 падає з `RecursionError`, а `nested_stats_iter` і трамплін працюють
на будь-якій глибині, бо зберігають стан у списку чи циклі, а не в стеку викликів.
**Ітеративна версія безпечніша**, коли глибина даних заздалегідь невідома (дані
від користувача, файли, мережа). Піднімати `sys.setrecursionlimit` ризиковано:
можна вийти за межі стеку C і аварійно завершити інтерпретатор.
